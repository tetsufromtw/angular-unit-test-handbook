タイムアウト設定の例

💡 ポイント説明：

  • 第二引数でテストのタイムアウト時間（ミリ秒）を指定
  • 指定時間内にテストが完了しない場合、失敗としてマークされる
  • describe、it、beforeEach、afterEach などに適用可能

Promise 処理の例

💡 ポイント説明：

  • async/await を使用せずに Promise を返すことができる
  • .then() と .catch() を使用して成功と失敗の状況を処理
  • Promise が拒否されたときは .catch() でエラーをキャッチ

非同期テストのベストプラクティス

⚡

async/await を使用

現代 JavaScript では async/await 構文の使用が推奨されており、Promise チェーンよりも直感的で読みやすい

⏰

適切なタイムアウトを設定

操作の予想実行時間に基づいてタイムアウトを設定し、テストが無限に待機したり、早期に失敗したりしないようにする

🧹

リソースのクリーンアップ

afterEach の中で非同期操作によって作成されたリソースをクリーンアップし、テスト間の相互影響を防ぐ

🔍

エラー処理

非同期操作の成功と失敗の状況を明確にテストし、エラーが正しくキャッチされ処理されることを確認

学習ポイントのまとめ

async/await：現代の非同期テストの第一選択肢であり、構文が明確にで直感的
タイムアウト設定：第二引数でテストのタイムアウト時間を指定し、無限待機を防止
Promise チェーン：従来の Promise 処理方法であり、依然として有効で役立つ
エラー処理：try/catch または .catch() を使用して非同期操作のエラーを処理
