学習ポイント

beforeAll / afterAll

テストスイート全体の開始前/後に1回実行、重い初期化処理/クリーンアップ処理に使用

beforeEach / afterEach

各テストの前後に実行され、各テストがクリーンな環境を持つことを保証

this 上下文

各テストは独立した this オブジェクトを持ち、テスト間の汚染を防止

fail() 関数

テストを明確に失敗としてマークし、通常は実行されるべきでないコールバック関数内で使用
