Truthy/Falsy マッチャー

💡 ポイント説明：

  • toBeTruthy() は値が真偽値（truthy）であるかをチェック
  • toBeFalsy() は値が偽偽値（falsy）であるかをチェック
  • falsy と false の違いに注意

カスタムマッチャー

💡 ポイント説明：

  • jasmine.addMatchers() を使用してカスタムマッチャーを追加
  • compare 関数は必ず {{ '{' }} pass: boolean, message: string {{ '}' }} を返す必要があります
  • 柔軟な比較のために追加の引数を受け取ることができます

よく使うマッチャーリファレンス

基本マッチャー

toBe() === 厳密等価
toEqual() 深い等価比較
toBeNull() null であるかをチェック
toBeUndefined() undefined であるかをチェック
toBeDefined() 定義されているかをチェック
toBeTruthy() 真偽値をチェック
toBeFalsy() 偽偽値をチェック

数値マッチャー

toBeGreaterThan() より大きいか比較
toBeLessThan() より小さいか比較
toBeGreaterThanOrEqual() 以上か比較
toBeLessThanOrEqual() 以下か比較
toBeCloseTo() 浮動小数点数の精度比較
toBeNaN() NaN であるかをチェック

テキスト列マッチャー

toContain() 部分テキスト列を含むか
toMatch() 正規表現マッチ
toStartWith() ...で始まるか
toEndWith() ...で終わるか

配列とオブジェクト

toContain() 配列に要素が含まれるか
toHaveSize() 長さをチェック
toBeInstanceOf() 型のインスタンスかをチェック
toHaveProperty() プロパティの存在をチェック
objectContaining() 部分オブジェクトマッチ
arrayContaining() 配列部分マッチ

マッチャー使用のベストプラクティス

🎯

適切なマッチャーの選択

テストの要件に応じて最も適切なマッチャーを選択、toBe と toEqual、toContain と toMatch の使い分け

📏

浮動小数点数の取り扱い

浮動小数点数の比較には toBeCloseTo() を使用し、精度問題によるテスト失敗を回避

🔍

明確にな期待値

具体的なマッチャーを使用して明確な期待値を表現、あいまいな toBeTruthy() などは避ける

⚙️

カスタムマッチャー

繰り返し使用する複雑な検証ロジックには、カスタムマッチャーを作成して可読性を向上

学習ポイントまとめ

基本マッチャー：toBe() は厳密等価に、toEqual() は深い比較に使用
数値マッチャー：サイズ比較と精度処理を提供し、数値検証に適用
テキスト列マッチャー：含むチェックと正規表現マッチングをサポート
配列オブジェクト：内容、サイズ、型、構造を検査する専用マッチャー
